# Payment Icons

Place your payment method PNG icons in this folder.

## Supported Icon Names:

- `cash.png` - Cash payment
- `credit-card.png` - Credit card
- `debit-card.png` - Debit card
- `bit.png` - Bit payment (Israel)
- `paybox.png` - PayBox
- `bank-transfer.png` - Bank transfer
- `apple-pay.png` - Apple Pay
- `google-pay.png` - Google Pay
- `paypal.png` - PayPal
- `stripe.png` - Stripe
- `venmo.png` - Venmo
- `zelle.png` - Zelle
- `western-union.png` - Western Union
- `money-order.png` - Money order
- `check.png` - Check
- `cryptocurrency.png` - Cryptocurrency
- `bitcoin.png` - Bitcoin
- `ethereum.png` - Ethereum
- `other.png` - Other payment methods
- `not-paid.png` - Not paid

## Recommended Specifications:

- Format: PNG with transparent background
- Size: 256x256px or 512x512px
- Color: Full color or monochrome
- Style: Flat design or outlined icons work best

## How to Add Icons:

1. Save your PNG icon in this folder
2. Use one of the names listed above (or add a new one to the list in `IconPickerModal.tsx`)
3. The icon will automatically appear in the icon picker modal when you open the payment methods settings
4. Click on any payment method icon to open the picker and select your new icon

## Example:

```
payment-icons/
├── cash.png
├── credit-card.png
├── bit.png
└── apple-pay.png
```
